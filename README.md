  &nbsp;DocMinds &nbsp;<sub><i>document intelligence &amp; semantic search</i></sub>
</h3>

<table>
<tr><td width="62%" valign="top">

Multi-tenant **RAG platform** for enterprise documents. The upload service reads
**19 file extensions** using PyMuPDF, python-docx, python-pptx, openpyxl and
BeautifulSoup. It also opens ZIP archives and reads the files inside, and it sends
scanned PDFs to **Tesseract OCR** when a page has fewer than 100 characters.

**pgvector HNSW** index, so search stays fast as the corpus grows.

Questions are embedded the same way. The nearest chunks are found by cosine distance
and anything below a score floor is dropped. **Llama 3.3 70B on Groq** then answers
using only those chunks and shows the page it used.

  <img src="https://img.shields.io/badge/04-f472b6?style=flat-square&label=&labelColor=f472b6" alt=""/>
  &nbsp;MiniRedis &nbsp;<sub><i>a Redis-style database, from scratch in C++20</i></sub>
</h3>

<table>
<tr><td width="62%" valign="top">

An in-memory database written from scratch, with **no database libraries and no networking
frameworks**. The **stock `redis-cli` connects to it without changes**.

A **single-threaded event loop** over `poll()`/`WSAPoll` handles thousands of connections
with no locks. An incremental **RESP2** parser stays correct when TCP splits a message.
**148 commands** cover strings, lists, hashes, sets and sorted sets. TTLs are reclaimed both
lazily and by active sampling, and `maxmemory` supports all eight eviction policies.

Data is made durable in two ways: a self-rewriting **append-only log** with three fsync
policies, and **CRC64-checked snapshots**. Leader/follower replication resyncs partially
from a ring backlog. **16384 hash slots** use Redis-compatible CRC16 with `MOVED`
redirection. It also has `MULTI/EXEC/WATCH`, pub/sub and `SLOWLOG`/`MONITOR`.

  &nbsp;GRIDSMITH &nbsp;<sub><i>deterministic table extraction from messy PDFs</i></sub>
</h3>

<table>
<tr><td width="62%" valign="top">

Every extracted cell is **either correct or flagged as uncertain**. No language model
touches the document. It uses only classical vision, text-layer geometry and signal
processing, it is enforced to run offline, and its output is byte-for-byte reproducible.

It is measured by **silent errors**, not accuracy. A silent error is a wrong cell that
ships with confidence and no flag. There are **0** across 202 hand-labelled cells.

It handles the ways PDF tables actually break: documents that draw 18,066 tiny squares instead
of ruled lines, columns that drift ±2 pt across six pages, a scale stated in a sentence above
the table, and footnotes that continue onto the next page. It also **refuses** things that only
look like tables, such as contents pages, indexes and two-column prose. Both off-the-shelf
baselines extract those as data.

  <img src="https://img.shields.io/badge/06-8b5cf6?style=flat-square&label=&labelColor=8b5cf6" alt=""/>
  &nbsp;SentinelGraph &nbsp;<sub><i>graph-based fraud detection</i></sub>
</h3>

<table>
<tr><td width="62%" valign="top">

Fraud is rarely visible in a single row. One account receiving $4,000 is
unremarkable. Ten accounts each sending $4,000 into one account that immediately
wires 95% of it offshore is a mule funnel. Neither is a property of one record.
Each is **a shape in the network**, and that's what SentinelGraph looks for.

It's built on **CognoDB** with openCypher over Bolt. The ring detector is one line,
`(a)-[:TRANSFERRED*3..5]->(a)`, where the depth is just a parameter. The relational
version needs a recursive CTE with a hardcoded depth and a manual cycle guard.

Risk scoring **combines the individual shape detectors** instead of replacing them, so
every flagged account can be traced back to the exact pattern and path that raised it.

<p align="left">

Nothing on this page is pasted in twice.

| Piece | Where it comes from |
|---|---|
| **Hero, rules and pipeline** | [`scripts/gen_neon_assets.py`](scripts/gen_neon_assets.py). Pure SMIL, no dependencies. GitHub strips `<script>` from markdown and ignores CSS `:hover` inside an image, so nothing in a README can react to your cursor. What it *can* do is keep moving: gradient stop colours rotate through four accents, a highlight sweeps across the letters, and packets travel down the wire. Both themes come from one definition. |
| **Section titles and counters** | [`scripts/gen_motion_assets.py`](scripts/gen_motion_assets.py). Letters rise in one by one, a wave ripples through them, the fill cycles through the accents and an RGB-split glitch fires now and then. Headline numbers sit on odometers that roll each digit into place. |
| **Live cards** | [`scripts/gen_live_assets.py`](scripts/gen_live_assets.py), run every 30 minutes by [`live.yml`](.github/workflows/live.yml) and force-pushed to the orphan `live` branch so the refreshes never pile up in history. The New Delhi sky follows the real clock, sunrise and weather; the terminal, Codeforces chart, contribution pulse and commit ticker read the Codeforces, LeetCode and GitHub APIs. If a source is down, the last good value is reused. |
| **The 3D pieces** | [`scripts/gen_3d_assets.py`](scripts/gen_3d_assets.py) projects real geometry at 25–37 keyframes and bakes the frames into SMIL, so the browser interpolates between projected frames. |
| **RECENTLY PUSHED** | [`scripts/update_readme.py`](scripts/update_readme.py) reads the GitHub API and rewrites only the text between two markers, so the hand-written parts are never touched. Runs daily. |
| **Commit calendar and snake** | [`github-profile-3d-contrib`](https://github.com/yoshi389111/github-profile-3d-contrib) and [`Platane/snk`](https://github.com/Platane/snk), regenerated nightly. |
| **Theme awareness** | Two images per slot, one tagged `#gh-light-mode-only` and one `#gh-dark-mode-only`. GitHub hides whichever one doesn't match your theme. |

```bash
python scripts/gen_neon_assets.py   # 6 files: hero, rule, pipeline x light/dark
python scripts/gen_3d_assets.py     # 12 files: 6 pieces x light/dark
python scripts/gen_motion_assets.py # 34 files: 11 titles + 6 counters x light/dark
python scripts/gen_live_assets.py --out live-out   # what the live branch holds
```
